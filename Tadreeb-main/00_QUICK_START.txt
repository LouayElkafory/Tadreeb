================================================================================
                    TROUBLESHOOTING
================================================================================

Q: Port 5173 already in use?
A: cd Frontend && npm run dev -- --port 5174

Q: Port 8000 already in use?
A: Edit 06_app/main.py and change port, or:
   uvicorn 06_app.api:app --reload --port 8001

Q: Missing dependencies?
A: pip install fastapi uvicorn pydantic pymupdf PyPDF \
   sentence-transformers faiss-cpu numpy pandas langdetect

Q: npm not found?
A: Install Node.js from https://nodejs.org/

Q: Frontend not connecting to API?
A: Check that backend is running: curl http://localhost:8000/health

Q: Cannot find PDFs for indexing?
A: Add PDFs to: 02_data/01_raw/<organization>/official/
